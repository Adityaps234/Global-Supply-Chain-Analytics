# Global Supply Chain & Logistics Analytics
### Project Overview
This project analyzes over 110,000 records of global supply chain data, tracking freight costs, port congestion, and global disruption events from 2000 to 2024. The goal was to build a Logistics Control Tower dashboard to help operational leaders identify shipping bottlenecks and monitor the financial impact of geopolitical events.
### Tools Used 
**Python**: Cleaned and processed four distinct logistics datasets (over 110,000 rows).

**PostgreSQL**: Wrote 11 advanced business queries utilizing CTEs, Window Functions, and CASE statements to calculate price volatility and year-over-year freight spikes.

**Power BI**: Engineered an interactive, executive-level geospatial dashboard using custom DAX measures.
### Key Business Insights Discovered
1. Geopolitical events caused the highest number of severe supply chain disruptions, directly correlating with massive spikes in global shipping costs.
2. The peak cost of exporting goods hit an all-time high in 2021, with container rates jumping significantly year-over-year.
3. The geospatial map highlights that major ports in Asia experience the highest average wait days, creating a massive bottleneck for global inventory.
